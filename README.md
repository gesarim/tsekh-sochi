# ЦЕХЪ

Адаптивный прототип сайта швейного производства в Сочи. React, TypeScript, Tailwind CSS и Vite.

## Запуск

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`. Её можно развернуть на статическом хостинге с поддержкой индексных файлов каталогов и страницы 404. Многостраничная сборка содержит 22 маршрута, Sitemap и отдельные метаданные. Исходный проект настроен на домен из `src/content.ts`.

## Данные и приём заявок

- Контакты, реквизиты, тексты услуг и ссылки на изображения заданы в `src/content.ts`.
- Для подключения заявки передайте `VITE_LEAD_ENDPOINT` при сборке. Клиент передаёт `multipart/form-data` с полями `type`, `stage`, `volume`, `description`, `deadline`, `name`, `phone`, `messenger`, `consent` и файлами в повторяющемся поле `attachments`. Успешный ответ — HTTP 2xx и JSON `{"accepted":true}` после сохранения заявки. Сервер отвечает за проверку данных и файлов и передачу в CRM.
- Для публикации заменить демонстрационные кейсы и иллюстрации на подтверждённые материалы, добавить видео производства, адрес, контакты и официальный текст политики обработки персональных данных. Добавить карту после подтверждения адреса. Уточнить доступность услуг и условия дистанционной работы.
